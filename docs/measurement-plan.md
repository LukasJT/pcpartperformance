# Measurement plan

Track Search Console impressions, clicks, indexed pages, canonical issues, queries, and page groups. Track completed comparisons and builds without recording selected hardware as sensitive user profiling.

For ads, compare eligible page views, consent rate, viewability, fill, revenue per thousand eligible views, completed comparisons and builds, return visits, and Core Web Vitals by page type and device. Stop or reduce a placement if it materially harms navigation, layout stability, interaction, or task completion.
