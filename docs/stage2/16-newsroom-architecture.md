# newsroom architecture

Prepared October 4, 2026. Local release; deployment confirmation is not recorded.

## Scope
Main navigation retains Compare, Hardware, PC builder, FPS, Blog and Shop. A resource subnav/footer connects Newsroom, Phones, Tools, Data, Search and Saved. This avoids an overcrowded global header.

Blog remains the evergreen publication. Newsroom uses source-led event reporting with a draft queue; no breaking-news claim is made merely because a hub exists. Phones starts as a focused five-record cohort with useful size/support tools. Laptops, general technology headlines and generic deal articles are held until a maintained dataset and differentiating evidence exist.

## Competition and differentiation
TechPowerUp’s first-party search result shows a developed GPU database; full retrieval was robots-blocked. RTINGS publishes measurement methodology. We do not copy either database or invent competitive weaknesses. The useful opportunity is explicit unknowns, board-specific topology, reproducible budget arithmetic and per-field evidence. Per-query demand/competition remains unmeasured.
