# source confidence system

Prepared October 4, 2026. Local release; deployment confirmation is not recorded.

Classify each claim: manufacturer specification; independently measured with identified setup; site calculation with explicit inputs; company forecast; inherited unverified field; unavailable. Primary status establishes source origin, not truth beyond its scope.

The phone dataset stores this per field. Board checker points to the exact MSI document. Catalog audit says field coverage is not correctness. Community questions only motivate research; they never validate specifications or demand volume.

If sources disagree, retain both citations, model/region/revision and an unresolved note. Stop the affected recommendation rather than average conflicting values. Correction review must trace all affected comparisons.
