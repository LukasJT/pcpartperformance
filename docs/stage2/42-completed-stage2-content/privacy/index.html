Privacy and browser storage

How the current interface handles preferences and external links.

Preferences on this device

The interface stores your light/dark theme and shopping country in browser local storage. The new saved list stores up to 100 product or resource IDs on this device. It does not create an account, synchronize between devices, monitor prices or send an email alert. Clear the saved list on its page or clear this site’s browser data to remove it.

Search and calculators

Local search downloads the public search index and matches your query on this device. It does not send the text to an external search service. Planning calculators use your entered values locally; this release does not transmit those inputs to an analytics service. Public dataset downloads contain catalog aggregates or sourced phone facts, not your saved list.

External services and links

The existing design can request fonts from Google Fonts. Product photography, source links, retailer links and 3D-preview dependencies can involve external providers with their own policies. Following a YouTube or retailer link opens that service. The resource center does not autoplay or embed its video. This description does not claim the entire site makes no third-party requests.

Advertising and measurement

This publication release adds no active advertising script or analytics destination. Future activation requires the actual publisher account, consent implementation and an updated policy that identifies the applicable business and services. The default-off code gate is not a full consent-management platform.

Questions and corrections

Use the editorial correction page for a source or product-data error. Repository issues are public; do not include private contact details, account data or serial numbers. This operational description is not a substitute for an owner-specific legal privacy policy.
