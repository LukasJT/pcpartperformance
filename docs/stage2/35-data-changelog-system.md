# data changelog system

Prepared October 4, 2026. Local release; deployment confirmation is not recorded.

Public /data/changelog/ records the prepared release, additions, coverage version and unresolved fields. It does not claim confirmed live deployment. Future entries identify old/new value, source URL/date, affected model IDs/pages, reviewer role and material reason.

Preserve old dataset versions when public consumers need reproducibility. A rebuild or source availability check is not a substantive revision. Unknown publication dates remain unknown. Support end-date additions require anchor evidence. Exact-photo corrections require actual identity verification, not a relabeled family image.
