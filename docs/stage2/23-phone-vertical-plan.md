# phone vertical plan

Prepared October 4, 2026. Local release; deployment confirmation is not recorded.

## Decision
Launch a small specification/tool cohort, not a generic phone-news division or newest-phone ranking. The current catalog already includes phones; a first-party comparison question supports qualitative interest, not a volume estimate. Manufacturer dimensions create an original same-scale tool without a test lab.

## Implemented
Five records; two focused comparisons; same-scale size overlay; policy-evidence tracker; per-field null/source/check/confidence. Exact regional SIM/network fields and fixed support end dates are held.

## Hold
Battery/camera winners, repairability scores, charging speed predictions, newest-generation recommendations and live offers require verified source data or original tests. A charger checker needs exact protocol/cable/adapter contracts; it is not reduced to wattage.

## Growth gate
Use Search Console and real support questions to justify additions, then source each model/region. Do not generate every phone pairing.
