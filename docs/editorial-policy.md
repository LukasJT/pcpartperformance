# Editorial policy

Technical pages distinguish specifications, compatibility checks, estimates, synthetic results, and application or game measurements. Missing data stays missing. Exact model numbers and manufacturer support pages take priority over generic assumptions. Family and reference images remain labeled.

Articles answer a hardware decision, link to relevant tools, state important limits, and direct readers to primary product documentation. Dates change only after substantive review. Corrections should update the source data or generator so every rebuilt page stays consistent.
