## Externally dependent outcomes

- Broad retailer feeds/APIs need supported data sources and, where required, accounts/permission. Ordinary public reads do not bypass access gates. No invented lowest-price or stock state.
- Exact downloadable assets and redistribution licences are required before a model is published. Catalog geometry and thermal fit are distinct.
- Measured PC FPS needs actual comparable measurements and permitted use; a software model/protocol is not a measurement.
- Human editorial review is not supplied by automated validation. Any required complete-article review remains truthful and explicit.
- Search Console, active analytics delivery, field Core Web Vitals, account synchronization and notification services are not inferred from a successful build.

These dependencies do not stop independent implementation, research, integration or QA. Record the exact boundary per feature rather than declaring the whole program complete.
