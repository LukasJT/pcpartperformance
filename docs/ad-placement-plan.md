# Advertising placement plan

Placements and vendor documents are enabled after affirmative consent and near-viewport visibility. They are labeled and kept out of primary controls. Responsive horizontal placements select 728×90, 468×60, or 320×50 by measured container width. Product pages use one 300×250 unit. Native units appear only after substantial content. The 160×300 and 160×600 tags are configured for future rail placements; the current page templates do not request them.

Every vendor script runs in a cross-origin iframe with `sandbox="allow-scripts allow-same-origin"`, using the alternate site domain. Popups, top navigation, new-window permissions, automatic redirects, autoplay and notifications are not permitted. Ad inventory and fill are controlled by Adsterra; an enabled tag does not guarantee a filled impression.
