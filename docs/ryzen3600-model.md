# Ryzen 5 3600 model

Downloaded AMD Ryzen by Zambur, CC BY 4.0:
https://sketchfab.com/3d-models/amd-ryzen-a40ff370b7534232864f4ec2f101dd1c

The source texture identifies AMD Ryzen 5 3600, matching existing record `3600`. Original 1K-texture GLB is `../zambur-ryzen/source.glb` (18,685,948 bytes).

Flattened transforms, consolidated 1,771 meshes into one primitive, simplified with ratio 0.4/error 0.001, quantized and pruned. Final asset: 7,793,372 bytes. Retained source appearance and texture. Rotated X +90 and Y -90 degrees so the heatspreader faces forward with readable horizontal text.

Browser verified model loads and orientation is correct. Approximate package dimensions remain; no independent contact-position or cooler-clearance certification.
