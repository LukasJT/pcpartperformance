Checked all 148 catalog records: 118 repaired, 29 existing exact photos retained, 1 unresolved model identity.

- case: 85 records; 81 repaired, 3 retained, 1 unresolved.
- fan: 50 records; 26 repaired, 24 retained, 0 unresolved.
- cooler: 13 records; 11 repaired, 2 retained, 0 unresolved.

All 118 repaired entries have local WebP images bounded by 800 px and 320 px thumbnails, source and image URLs, explicit pictured-model identity, copyright/attribution notes, SHA-256 values and inspected contact-sheet references. All accepted images were visually inspected across the eight case-cooling contact sheets. An incorrect NZXT recommendation image, Phanteks logo, Fractal recommendation image and black EVO color candidate were rejected and replaced before approval.

The existing Corsair photo is incorrect; integration must remove it or show a clear unavailable-photo state until an exact manufacturer model is supplied.
