# Deployment

Run `npm run build`, then `node scripts/check-site.cjs`. The publication directory is `dist`, as declared in `.openai/hosting.json`.

After deployment, verify the public homepage and representative category, record, guide, article, builder, privacy, robots, sitemap, and missing-page responses. Inspect the network panel to confirm no advertising-domain request occurs before consent. Any future enabled ad must be verified unable to open a new window or navigate the top page. The repository's saved Sites project ID must resolve in the publishing workspace before replacing the existing deployment.
